## Data availability

The code that implements PhysINR-Zero, the benchmark harness, the dataset
manifests, the evaluation code, all measured results and the per-run
provenance records are available in the project repository at
<https://github.com/bornaseirco/PhysINR>.

<!-- PROPOSAL REQUIRING CONFIRMATION: the URL above follows the repository
     owner's GitHub account. Replace it with the canonical address (or a
     deposited DOI) if it differs. -->

The benchmark datasets themselves are not redistributed by the authors and are
obtained from their public sources: UIEB (Li et al., 2020), LSUI (Peng et al.,
2023), EUVP (Islam et al., 2020) and the RUIE benchmark including the UCCS
subset (Dalian University of Technology, n.d. [dataset]). Each dataset is
verified in the harness against a sha256 manifest, and every split is checked
for disjointness, before any method is scored on it.
